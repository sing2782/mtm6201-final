# mtm6201-final

MTM6201 Final Website Project
Overview

This project is my final assignment for MTM6201 – Web Development.
The website was built using Bootstrap, a second public CSS library, and custom CSS variables. It contains three pages based on my UX mockups and Figma designs.

Figma link: https://www.figma.com/design/zuKEctiE6o0r3k59SIqd1s/prototype?node-id=0-1&t=KPhH39ZlyGJpqvWT-1

Process

I started by reviewing my UX wireframes and turning them into a responsive layout using Bootstrap’s grid and components. I customized the colour scheme using CSS variables and added a secondary CSS library for extra styling.
I ensured semantic HTML structure, alt text, aria labels, and optimized images using <picture> and srcset.

Challenges

Customizing Bootstrap: Solved by using CSS variables and overriding components carefully.

Responsive images: Exported multiple sizes and optimized them for faster loading.

Accessibility: Added semantic markup, keyboard navigation, proper contrast, and ARIA attributes.

What I Learned

I learned how to customize Bootstrap, work with responsive images, improve accessibility, follow naming conventions, and publish a site using GitHub Pages. This project helped me understand how UX mockups translate into real code.
